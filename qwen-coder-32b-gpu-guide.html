How Much GPU Memory You Actually Need for Qwen 2.5 Coder 32B

When you run a coding model with a 32,000-token context window, your graphics card memory (VRAM) gets used by two things: 1) The model weights and 2) The scratchpad (context cache) that remembers your open files and chat history.

4-Bit (AWQ / Q4_K_M) vs 8-Bit (FP8) at 32k Context

Version Weights + 32k Scratchpad Best GPU to Rent Live Hourly Price 1-Click Launch
4-Bit (AWQ / Q4_K_M) + FP8 Cache ~22.4 GB total 1x RTX 4090 (24GB) or 1x RTX 3090 (24GB) $0.19 – $0.35/hr Launch vLLM →
4-Bit (Q4_K_M) w/ 64k Context ~27.8 GB total 1x RTX 5090 (32GB) $0.67/hr Launch Ollama →
8-Bit (FP8) Native ~38.0 GB total 1x L40S (48GB) or 2x RTX 4090 (48GB) $0.46/hr Launch 48GB Box →

Quick Recommendation for VS Code / Continue

Stick to the 4-bit version (AWQ or Q4_K_M) with 8-bit cache turned on. It fits on a single 24GB card (or 32GB RTX 5090 if you want a huge 64k context window) and writes code just as well as the heavier 8-bit version for half the hourly price. 

docker run --gpus all --shm-size 16g -p 8000:8000 vllm/vllm-openai:latest \
  --model Qwen/Qwen2.5-Coder-32B-Instruct-AWQ \
  --quantization awq \
  --kv-cache-dtype fp8 \
  --max-model-len 32768
